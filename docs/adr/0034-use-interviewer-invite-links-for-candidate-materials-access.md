# Use interviewer invite links for candidate-materials access

Human-interview interviewer invite links are bearer credentials for meeting entry and read-only access to candidate materials. Access is independent of the workspace session. A valid link identifies a host, interviewer, or observer for audit attribution and scopes all queries to candidates attached to that meeting. Candidate-side invites cannot grant this access. The link can be forwarded so invited interviewers can use the meeting experience without signing in.

Materials remain available while the meeting is in progress and for 24 hours after its actual end. When no actual end is recorded, the window uses the meeting's current scheduled end, including any reschedule. Cancelling the meeting or expiring the signed invitation closes access immediately.
