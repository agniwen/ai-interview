# 在候选人详情使用原地展开的操作 Dock

决策日期：2026-09-17。

## 背景

招聘台候选人详情的 floating bar 将节点确认、结束、重新激活、面试安排等操作交给独立弹窗。遮罩、位置跳转和焦点锁中断了阅读候选人资料的连续过程。各按钮还分别持有表单及提交逻辑，直接复制成内联版本会产生两套业务规则。

## 决策

页面形态的候选人详情使用一个底部固定、向上展开的 Candidate Action Dock。动作的填写、确认、提交中和错误反馈均在同一表面呈现；背景资料保持可操作。直接动作不增加确认。其他入口继续使用弹窗，共用同一份字段、校验和提交实现。

分离三项职责：Dock 管理位置、形变、焦点和当前流程；流程控制管理打开、暂存和结束；各业务流程持有字段、校验、步骤及请求。使用 React context、reducer 和类型化流程标识，不引入全局状态或通用 JSON 表单引擎。流程在固定的内容槽内呈现，外壳不因动作切换卸载。新增流程接入统一 surface 与流程控制契约，不修改动效实现。

“返回操作”暂存当前流程，同一详情会话重新进入时继续填写；“上一步”由多步骤流程提供并保留字段；显式“放弃填写”清空流程。离开候选人或工作区清除内存草稿，不持久化敏感招聘内容。提交中禁止重复提交和退出该流程。错误保留输入并在操作区展示；服务端成功后结束流程并刷新数据，不将缓存刷新错误解释为业务提交失败。

保留服务端权限、阶段约束、expectedVersion 和所有原始字段语义。编辑期间的数据更新不静默覆盖草稿；版本冲突要求用户核对最新记录。候选人切换卸载旧流程，旧请求不能修改新候选人的 Dock。流程局部状态不能依赖 record.version 作为 React key。招聘阶段使入口失效时，过期草稿不得重新用于新阶段。

Dock 局部使用 `LazyMotion features={domMax}`，因为根布局的 `domAnimation` 不提供布局投影能力；不扩大整个应用的动画功能包。动效复用项目中的 Motion：外壳与内容的 layoutAnchor 均设为底部中央；一级工具栏独立参与缩放补偿，并将外壳 MotionContext 传给业务子树，避免 portal 内容继承隐藏工具栏的坐标。底部中央锚点稳定，外壳向上展开、向下收拢，内容沿竖直方向轻量切换，快速返回可以中断动画。外壳使用无回弹的 320ms tween，形变开始约 64ms 后，整个 action 面板（含标题、表单与页脚）在剩余 256ms 内渐显，与外壳同时完成。两阶段共享外壳时长并重叠执行，通过声明式 animate 驱动透明度与竖直位移，首次挂载、重新进入和动画中断都由当前状态决定目标，避免在 layout effect 中启动命令式动画而错过订阅；步骤切换保持内容连续，返回操作时内容先向下淡出 100ms，再向底部收拢外壳；一级操作内容在收拢过程中用 CSS 从上方 8px 下移并渐显，渐显使用内层普通 DOM，外层 layout="position" 补偿外壳缩放，避免文字和按钮拉伸；外壳使用 overflow-hidden 将变换中的内容裁切在原有圆角内，防止收拢时完整宽度的一级内容越界，选择器浮层继续通过 portal 呈现。一级与二级共用外壳的 bg-background/70、backdrop-blur-xl 与 backdrop-saturate-150 毛玻璃材质；取消时停止旧动画且不重挂载表单；减少动态效果时取消位移和形变。表单内容避免缩放失真，滚动内容区与固定页脚分开，窄屏适配可用视口和软键盘。收起与展开沿用原 floating bar 的圆角、边框、阴影和底部外间距，避免视觉体系跳变。展开态保留操作栏的紧凑密度：标题 14px、辅助文本 12px、桌面字段约 13px、轻边框和小间距；窄屏输入仍保留可读字号，返回与底部操作按钮沿用原 bar 的 44px 高度和 text-sm 字号，桌面保持紧凑。真人面试安排拆为“时间与轮次”和“面试官与备注”两步。

Dock 不加遮罩、不使用全页焦点锁、不因外部点击关闭。进入后聚焦操作标题，返回后恢复入口焦点；Esc 优先交给内部选择器，中文组合输入期间不返回。日期、成员等选择器仍可使用锚定浮层；独立的成员管理等非招聘操作不纳入该流程。

## 取舍与验证

不使用 GSAP：当前需求由 React 状态驱动，现有 Motion 足以承载形变，避免两套动画生命周期。不将所有流程集中成巨型 reducer；宿主只协调流程，字段仍归业务所有。

迁移覆盖 floating bar 的节点结果、轮次重置、结束/重新激活、AI 面试发起、真人面试安排及推进时的问题确认。Offer 等详情正文入口仍使用原有呈现，后续可复用同一 surface。

回归验证返回后草稿恢复、放弃后重置、失败后重试、重复提交保护、候选人隔离、数据刷新、焦点恢复、内部浮层 Esc、减少动态效果及窄屏布局。保留现有业务测试并运行 Web 类型检查和改动文件检查。
