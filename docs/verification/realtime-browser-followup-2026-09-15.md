## 发现的问题

1. **有效回答没有完成归档。** 1539 的七题有答案，但状态保持 in_progress，结束变成 interrupted。报告整体却称已提供所需信息，题目分析显示中断。最后一条回答的部门细分、每日订单量和故障改善信息也没有完整合并到项目记录。
2. **网页主动结束没有及时通知 Agent 结束。** 8689 在网页确认结束后仍按断线等待重连，约 172 秒后报告才提交。最终由 Qwen 空闲超时关闭，产生 RealtimeError 和 FFI handle 警告。报告最终 ready，但用户会等待很久。
3. **“最近一次”的 UI 含义不清。** 旧的 8689 延迟回调后，数据库当前轮次的 room/conversationId 仍正确指向 1103，独立报告没有被覆盖；但 UI 把 22:17 的 8689 标成“最近一次”，22:22 的 1103 成了第二条。
4. **拒答与没有经验需要区分。** 8689 的“没有使用过 AI 工具”被标成 insufficient；它本身是有效事实。报告对信息不足给出 5/100，也容易把信息覆盖率误解为能力分数，应继续检查评分语义。
5. **自托管环境音频过滤器未生效。** 四个 Agent job 都有 audio filter on_load rejected，提示需要 LiveKit Cloud；会话继续运行，但不能声称降噪已验证成功。
