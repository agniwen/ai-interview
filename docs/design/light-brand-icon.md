# 亮色品牌图标

- 源文件：`apps/desktop/build/echo-multicolor-light.icon/`，从 `echo.icon` 复制；原文件保留。
- 渐变：珊瑚色 `#EEA28E` 到蓝色 `#6887DE`，中间自然过渡为淡紫。
- 保留 AI Pebble 原图层、材质和轮廓。精确颜色写入源文件后，在 Icon Composer 中确认并通过 File → Export 导出 macOS / Default / 1024pt / 1×。
- 导出原图：`apps/desktop/build/icon-multicolor-light.png`。
- 网页侧栏及共享品牌组件：`apps/web/public/logo-multicolor-light.png`，256px。
- 网页亮色 favicon：`apps/web/public/favicon-multicolor-light.ico`，包含 16、24、32、48、64、128、256px PNG 帧，保留透明度。
- 暗色 favicon 仍使用原有资源。桌面应用打包图标未切换。
