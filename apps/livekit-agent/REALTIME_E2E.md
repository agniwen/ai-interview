## 根据复现修复的问题

1. 无用户消息时 Qwen 报 `invalid_value`，以及错误后页面停留在连接态。
2. 复杂数组工具参数缺字段/错误编码：业务工具改为扁平字段、单项保存；协议层展开有限的本地 JSON Schema 引用。
3. 草稿和自由文本 reason 与回调契约不一致导致 HTTP 400：增加 `in_progress`，业务拒答原因放入摘要。
4. 刷新时 UI 计时和静音选择丢失。
5. LiveKit 默认离开 20 秒回收房间，早于应用重连窗口：签发房间配置时设置 `departureTimeout=240` 秒。
6. 收尾遗漏“没有补充”并误判部分完成：结束工具支持保存最终回答，完成度基于实际剩余条目。
