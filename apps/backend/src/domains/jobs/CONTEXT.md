# Jobs

Jobs owns the position being recruited for and the immutable criteria consumed by candidate evaluation.

## Language

**Job Evaluation Version**:
An immutable version of the job description and evaluation contract used to evaluate candidate evidence.
_Avoid_: Current JD row, worker-generated fallback

**Recruitable Job**:
A Job Description currently eligible to receive new Candidate Recruiting Records.
_Avoid_: Published job, active interview
