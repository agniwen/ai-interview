# Recruiting Setup

Recruiting Setup owns reusable workspace configuration selected when a job or interview is prepared.

## Language

**Recruiting Setup**:
The workspace-owned departments, interviewers, candidate forms, question templates, and defaults available for recruiting work.
_Avoid_: Job configuration, interview runtime

**Recruiting Setup Snapshot**:
A versioned, immutable selection of recruiting setup used by a Job Description or interview round.
_Avoid_: Live template, mutable configuration
