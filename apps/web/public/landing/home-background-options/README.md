## 生成提示词摘要

这些图片使用 Codex 内置 ImageGen 生成。所有方向共享以下生产约束：

- 16:9 全屏网站背景，服务于当前居中的 Hero 标题、说明和 CTA。
- 中央上方 60%–65% 保持低细节、低对比的文字净空；画面重量集中在两侧与下缘。
- 原创印象派油画、断色笔触、可见画布肌理和莫奈式光色氛围。
- 不含文字、字母、Logo、水印、设备、界面、边框或 3D 元素；A–D 不含人物。
- 亮色版以珍珠白、雾蓝、淡薰衣草和少量 `#1d4ed8` 为主。
- 暗色版以同构图重绘为蓝调夜景，使用 `#07111f`、`#0f1d45`、`#1d4ed8`、深群青和烟紫；不是对亮色版套压暗滤镜。

各套场景增量：

- A：晨雾河面、远岸和淡化的桥，细节落在左右河岸与下缘。
- B：略俯视的睡莲池与柳影，中央保留大块平静水面反光。
- C：外侧白杨与野草框景，路径从下三分之一处进入远方薄雾。
- D：低地平线云海与开阔天空，表现为接近抽象渐变的印象派云层。
- E：现代都市广场、办公建筑、通勤与相遇的人群，以连廊和克制的蓝金笔触表现人才、组织与机会之间的连接；中央上方继续保留标题净空。
- F：高视点城市全景，河流、桥梁、交通线与多个城区延伸到地平线，人物缩小为尺度参照，以城市级人才网络取代局促的中庭感。
- G：可信的非对称河城、混合年代建筑、电车、桥梁和自然活动的人群；通过真实城市流动表达连接，不使用发光网络或未来城市符号。
- H：保留 G 的高视点河流、电车、人群和大面积天空，将历史建筑更新为当代交通枢纽、文化建筑与两组错落的办公高楼；以石材、金属框架和克制玻璃构成成熟 CBD，不使用未来城市符号或玻璃塔墙。
- I：在 H 的基础上移除约三分之二高楼，以中低层当代街区、树冠和雾化间隙打散天际线，保留少量办公楼地标。
- J：完全重构为较低的人本视点，以宽阔河面和中景桥梁形成连接主轴；高楼退到左侧远景，右岸以现代中低层办公与文化建筑构成非对称框景。
- K：以参考图的建筑水彩、铅笔线稿、地图纸张拼贴和城市峡谷透视为视觉语言；绿色手绘路径穿过广场人群并延伸到纸张天空，表达候选人、岗位与组织之间的流动连接。

暗色图均以对应亮色图为构图参考，只改变时间、光照、氛围与色板，保留主题切换时的视觉连续性。
