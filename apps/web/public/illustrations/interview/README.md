# Interview entry backgrounds

The active light/dark abstract light-trail WebP assets are loaded by `InterviewEntryBackground` through theme-specific CSS URLs. AI interview preparation, form/pre-session flows, interview rooms, and the human interview entry shell reuse this background.

The unused courtyard PNGs have been removed. Generation prompts and actual image dimensions are documented in [interview preparation artwork](../../../../../docs/design/interview-preparation-artwork.md).
